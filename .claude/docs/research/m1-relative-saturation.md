## Definition

**Relative saturation** measures convergence of EGTR output across resolution levels, using each image's own Level-20 (full-resolution) output as the reference (pseudo-GT), instead of the dataset's true ground truth scene graph.

- `RelNodeRecall(t) = |nodes(t) ∩ nodes(20)| / |nodes(20)|`
- `RelTripletRecall(t) = |triplets(t) ∩ triplets(20)| / |triplets(20)|`
- `RelSGScore(t) = 0.5 * RelNodeRecall + 0.5 * RelTripletRecall`
- By construction, `RelSGScore(20) = 1.0`

**Caveat**: This measures CONVERGENCE/STABILITY of extraction, NOT correctness. Correctness is reported separately via the paper-protocol R@K (see `egtr-repro.md`).
