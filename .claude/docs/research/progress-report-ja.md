# 進捗報告: 解像度回復系列における観測停止判断の検証(10/7〜10/8)

(進捗報告用。代表的な結果のみ。数値は各報告書 `outputs/robovis2027/REPORT.md`、`outputs/robovis2027_recovery/rec_r0/REPORT.md` を参照。)

## 1. 取り組んだこと

生成型シーングラフ手法(Pix2Grp)を観測器として導入し、ローカルの視覚言語モデルで「いま見えている情報で十分か、さらに近づくべきか」を判断する停止手法を、Visual Genome の正解注釈に対して評価した。評価基盤として、公式評価と一致する採点、正解注釈に基づく品質指標、同じ観測量での比較、画像単位のブートストラップ検定、事前登録した検証手順を整備した。

## 2. 検証した仮説と結果

| 仮説 | 検証したこと | 結果 |
|---|---|---|
| 物体の共起性から「まだ見えていない物体・関係」を推測させ、その候補が残っている間は観測を続ければ、同じ観測量で正解の回収率が上がる | 視覚言語モデルに観測済みシーングラフから未確認候補を生成させ、候補を使う停止と使わない停止を比較 | **不支持。** 候補を使っても停止判断は変わらなかった。候補の中身は、シーングラフの不備の指摘や既に見えている物体の言い直しが大半で、実際に存在するのに未検出の物体を指すことはほとんどなかった |
| 候補が解像度を上げれば確認できるかどうかを、モデルが判断できる | テキストのみの判断器と、画像も渡す判断器で比較 | **不支持。** テキストのみでは判断不能。画像を渡しても「解決した」とほとんど言わず、極端に早い段階で止まる判断に偏った |
| 判断基準を緩め(大半が見えていれば解決扱い)、次の観測でどれだけ精細になるかを伝えれば判断が機能する | 判断器の指示を変更して再評価 | **部分的。** 解像度に追従する信号は出たが、同じ観測量のランダム割当を上回らなかった |
| モデルサイズを上げれば判断が機能する | 小さいモデルと大きいモデルで同じ構成を比較 | **部分的。** 小さいモデルは判断自体ができず、大きいモデルで初めて信号が出た。ただし優位性には至らず |
| 観測シーングラフのノイズを減らせば候補の質が上がる | 重複物体の統合と関係数の制限をした上で候補生成 | **部分的。** 実在する未検出物体を挙げる例が初めて現れたが少数で、停止判断には寄与しなかった |
| 過去の段階のシーングラフ履歴を与えれば判断が改善する | 直前数段階のグラフをテキストで追加 | **不支持。** 判断の傾向は変わらなかった |
| 「シーングラフが主張する物体が、画像のその位置にはっきり見えるか」を直接問えば継続判断ができる | 物体ごとに見え方を三段階で判定させ、途中で止めるか最後まで進むかの二択に使用 | **不支持。** 判定は解像度に追従するが、新しい画像集合では同じ継続率のランダム割当や検出信頼度だけの単純な規則に優位性がなかった |
| 停止則の重み付けを変えれば信号が回復する | 判断項目の集約方法を変えて再評価 | **不支持。** 問題は判断内容にあり、集約方法では回復しない |
| 生成型シーングラフ手法の内部的な一貫性(サンプル間の一致など)で停止できる | 追加のモデル呼出しなしで内部信号を算出 | **不支持。** 解像度段階の代理にはなるが、同じ段階の画像間を区別できない |
| 画像の精細さを直接読ませれば停止できる | 画像のみで「どれだけ細部が見えているか」を答えさせる診断 | **順序は読めるが絶対判定は校正できない。** タスク固有の判断になるため手法としては採用しない |
| 以前の発表と同じ枠組みで、飽和判定に現在画像を追加すると改善する | 既存検出器とシーングラフ系列の判定モデルに現在画像を添付 | **逆効果。** 停止が早まり精度が悪化。モデルは画像を根拠にせず、系列が安定したという事実と異なる説明を生成していた |
| 画像のみの判定とシーングラフのみの判定を後から組み合わせれば改善する | 条件を事前登録し、別の画像集合で検証 | **主規則は再現せず。** 副規則(両方が飽和と判断したときだけ止める)は理想的な停止時刻との一致で既存手法に有意に優位だったが、停止が遅く観測量が揃っていない |
| 適応的な停止は、固定段階で止めるより観測量あたりの回収率が高い | 既存手法を含め、同じ観測量の固定停止と正解注釈で比較 | **不支持。** どの手法も固定停止曲線から有意に離れなかった。なお固定停止は系列上の位置を知っている前提なので、公平な比較対象は段階非依存の手法に限定した |

## 3. 評価側で分かったこと

- 生成型シーングラフ手法は解像度に関わらず大量の候補を出し、画像ごとの品質曲線は 1 回のサンプリングの揺らぎに大きく左右される。追加の seed で確認すると、正解を知った上での理想配分による改善余地の半分程度はこの揺らぎだった。
- 以前の発表で画像判定がシーングラフ判定より劣ると読んだのは、閾値の不揃いによるもので、揃えると同程度だった。

## 4. 現時点の整理

- 当初の仮説(共起に基づく未確認候補が停止判断を改善する)は、いずれの構成でも支持されなかった。
- 画像を見せること自体の効果も、二つの枠組みのどちらでも停止精度の改善につながらなかった。
- 得られたのは、正解注釈と段階非依存の比較対象による評価枠組み、単発判定の校正の難しさと早期融合での作話という失敗分析、以前の発表結果の再解釈である。

## 5. 今後の論点

- 否定的・分析的な知見を主軸に原稿を組むか、副規則の有意な優位(観測量の但し書き付き)をどこまで前面に出すか。
- 共起に基づく候補生成は今回の構成では成立しなかったため、別の問題設定(質問意図に応じた十分性など)への接続を次案として記録するにとどめる。
